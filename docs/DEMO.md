## 演示流程

1. **问题**：谁在什么情境下遇到什么困难？
2. **操作**：展示一个完整的核心任务，避免逐页介绍界面。
3. **结果**：说明实际输出与可核验的价值，不把假设当成已测结果。
4. **限制**：指出 mock、数据边界与下一步。

## 演示前检查

- [ ] 从干净的克隆目录按 README 启动成功。
- [ ] `npm run check` 与新增模块的检查全部通过。
- [ ] 核心路径、空数据、加载和失败状态可解释。
- [ ] 已准备样例输入、重置步骤和备用方案。
- [ ] 屏幕、日志和录屏中不包含个人信息或凭据。
- [ ] 演示版本已记录，讲解与当前代码一致。
