# 开发路线 / Roadmap

以下是起步待办，开发前用 Issue 确认负责人和验收条件。 / This is an initial backlog; confirm ownership and acceptance criteria in Issues before implementation.

## M0 · 协作基础 / Collaboration foundation

- [x] 双语手册、协作模板和本地预览。 / Bilingual handbook, collaboration templates and local preview.
- [x] 工作区、契约与自动质量检查。 / Workspaces, contract and automated quality checks.
- [ ] 邀请成员并完成一次本地启动。 / Invite members and verify their local setup.
- [ ] 确认角色、审阅安排与分支保护。 / Confirm roles, reviews and branch protection.

## M1 · 定义 MVP / Define the MVP

- [ ] 从 Cathay AaaS 构想选择首个用户和核心场景。 / Select the first user and journey from the Cathay AaaS concept.
- [ ] 确认真实实现、mock 与排除范围。 / Define implemented, mocked and excluded scope.
- [ ] 确认框架、接口和样例数据，记录 ADR。 / Choose frameworks, contracts and samples; record an ADR.

## M2 · 完成核心流程 / Deliver the core journey

- [ ] 前端、接口与结果形成可运行闭环。 / Connect the UI, API and result into a working journey.
- [ ] 完善加载、空数据与失败状态。 / Handle loading, empty data and failures.
- [ ] 新模块具备契约、测试与 CI。 / Cover new modules with contracts, tests and CI.

## M3 · 演示与交付 / Demo and delivery

- [ ] 按 [演示手册 / Demo runbook](DEMO.md) 彩排并准备备用方案。 / Rehearse and prepare a fallback.
- [ ] README 准确记录功能与限制。 / Document actual capabilities and limitations.
- [ ] 核对提交物授权，记录 commit 和版本。 / Check asset permissions and record the delivered version.
