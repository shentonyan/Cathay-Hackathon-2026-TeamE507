## 備用操作

- **3D 不顯示**：說「這台電腦沒開硬件加速」，改講排程頁的曲線，不要在台上調設定。
- **想展示工程師視角**：登出，以 demo1／demo 登入。工作包可接收 → 開始 → 逐步勾選 → 簽署；也可「退回」或「提出異議」。再以 demo2 登入，總覽頁會出現「工程師回饋」，按「依回饋重新排程」即自動避開退回的時段。
- **想展示情景**：在排程頁點「減碳優先」，全年節省增至約 3,532 萬港元、減碳 8,736 噸；點「機庫減少一個」，全年節省約 2,224 萬港元。

## 評委可能追問

| 問題                            | 回答要點                                                                                                                                                                                                                                  |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 為甚麼只省 7.4%？               | 這是全年 26 期真的逐期求解的結果，不是把一期乘以 26。基準情景每年省 2,026 萬港元；減碳優先情景省 3,532 萬。現行做法本身已不差，我們的增量來自把耗油問題提早處理，以及共用資源的協調。                                                     |
| 一年的數字怎樣算？              | 全年滾動模擬：第 1 期是本期 21 項實際工作，之後每期按機隊規模產生新工作；備用發動機用掉後約 75 天才修好回庫，跨期延續；旺季其他飛機佔用更多工時。現行做法與聯合決策各跑一遍 26 期再比較。                                                 |
| 逐項最優為甚麼更便宜？          | 它只是紙面上便宜：同一天要 4 套清洗設備（只有 2 套）、3 個機庫位（只有 2 個），還要 3 台備用發動機同時用庫存，實際做不到。                                                                                                                |
| 為甚麼 DEMO-13 那一行成本變高？ | 系統把在站備用發動機讓給 DEMO-04，DEMO-13 改用租的，所以單項貴了約 230 萬。兩台合計仍省約 56 萬，因為耗油較多的 DEMO-04 提早 8 天修好。這是聯合排程和逐架排程的分別。                                                                     |
| 預測準不準？                    | 用美國太空總署公開的發動機退化數據訓練，誤差 10.65 個循環，比三篇公開研究低。90% 區間實際覆蓋 88%，快失效的發動機是 92%。正式使用要用國泰真實數據重新訓練。                                                                               |
| 數據是真的嗎？                  | 機隊、碳強度、油耗、維修開支都對照國泰 2025 年報和 2026 年中期公告。飛機編號、停場窗口、庫存是合成數據，頁腳「數據來源」逐項標明。                                                                                                        |
| 為甚麼是 20 架？                | 國泰約有 398 台發動機，每 14 天約有 3–4 台要換下。性能類問題在 14 天內約 15–20 項。例行定檢由現有系統負責。                                                                                                                               |

| 用了甚麼算法？                  | 剩餘壽命：多層感知器集成（15 個網絡）＋交叉共形預測區間；排程：0-1 整數規劃，精確分支定界求解。                                                                                                                                           |

## 數字速查（基準情景）

- 全年滾動模擬（26 期、484 項）：節省 HK\$20.26M（7.4%）；CO₂ 減少 8,273 噸；最高失效概率 3.0%
- 每期（14 天）：現行做法 HK\$7.30M → 聯合決策 HK\$6.59M；逐項最優 HK\$4.37M 但有 6 處衝突
- 減排成本：調整維修時機每減 1 噸 CO₂ 省約 HK\$1,870
- 工作：21 項（換發動機 3、保留故障 1、性能恢復 17），20 架飛機
- 2030 目標（差 76 g）：①本期排程 0.5% ②全集團推廣 2.3% ③機身性能保持 9.8% ④機身＋發動機 19.7%（15.0 g、333 千噸 CO₂、燃油節省約 HK\$625M／年）
- 情景（全年滾動）：基準 HK\$20.3M、機庫減少 HK\$22.2M、減碳優先 HK\$35.3M、備用發動機緊張 HK\$12.6M
- 預測模型：誤差 10.65 循環、NASA 評分 200、90% 區間覆蓋 88%
