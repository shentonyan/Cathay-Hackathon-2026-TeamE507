# 数据管理 / Data management

| 目录 / Directory                 | 规则 / Rule                                                     |
| -------------------------------- | --------------------------------------------------------------- |
| `samples/`                       | 可提交的合成或授权样例 / Commit synthetic or authorized samples |
| `raw/`, `private/`, `processed/` | 本地使用且已忽略 / Local-only, ignored by Git                   |

样例说明字段、单位、来源和生成方式。未确认授权的赛事资料、个人资料与签署文件保留在仓库外。当前尚无业务样例数据。 / Document fields, units, provenance and generation steps. Keep unauthorized event materials, personal records and signed documents outside the repository. No business sample dataset is included yet.
